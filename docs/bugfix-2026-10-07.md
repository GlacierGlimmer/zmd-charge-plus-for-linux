# 工单修复记录 — 2026-10-07

同步桌面端通用工单修复：非“常驻显示”模式自动轮播（ECP-5/44）、HTTP/JSON 示例解析与错误反馈（ECP-16/48）、颜色条件校验（ECP-22）和鼠标热区触发（ECP-76）。

轮播按队列执行显示/停留/隐藏；HTTP 配置兼容小驼峰字段，保存前校验，修改后刷新缓存；网络、鉴权及 JSON 路径错误显示诊断；颜色规则支持花括号变量、表达式、百分号和 Unicode 比较符，非法规则明确提示。

Linux 自定义 HTTP 字段在请求失败、JSON 无效或路径缺失时保留可读错误状态，避免变量被省略；GUI 审计覆盖这些失败路径。

托管构建及 procfs/sysfs、多电池和传感器缺失 fixture 检查已在 Windows 环境通过。原代码仍有平台分析警告；Linux 原生 GUI、打包与输入联动仍需在真实 Linux 文件系统验证。本记录不代表正式版本发布或工单关闭。
